# Folder get file list

Folder get file list is an action used to scan a folder on the computer and collect all the paths of the files inside that folder, then save them all into an array in the output variable.

This action is extremely useful when you have a folder containing a lot of images, videos, or configuration files and want to get that list to use a loop to process each file one by one, or to count the total number of files currently in the folder.
