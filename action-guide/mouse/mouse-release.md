# Mouse release

Mouse release is an action that commands the mouse, which is currently in a pressed-and-held state, to immediately release the left mouse button. This action has no complex configuration parameters and is always the mandatory final step for a drag-and-drop data sequence.

🎥 Watch more tutorial videos: [Here](https://youtu.be/kQZWs1I76Zo).

#### Practical application in command sequences:

This action combines with previous commands to fully complete a simulation task:

* Step 1: `Mouse press and hold` to press and hold firmly on a captcha slider or an interface element.
* Step 2: `Mouse move` to drag the mouse, moving that element to the target position.
* Step 3: `Mouse release` to release the mouse, completing the drop of the element at the new position so the website system can record the result.
