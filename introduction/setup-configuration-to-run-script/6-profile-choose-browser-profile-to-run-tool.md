# 👥 6. Profile (Select browser profiles to run the tool)

After finishing the configuration and schedule setup in the previous step, click `Continue` to move to step 3, which is selecting the browser profiles you want to apply the script to (interface as shown below). The actions here include:

**🤖 1. Select the control technology and browser application**

Looking at the menu bar above the profile list (as shown below), you need to set up:

* Core technology: Choose between Puppeteer enhanced engine or Selenium depending on the type of technology your script wants to use to control the browser.
* Browser application: Select the type of browser you are using to manage accounts, such as GPM Login Global, the old version of GPM Login, or GoLogin...
* Connection configuration: Click directly on the 🔌 API button right next to it to set up the Port and connection path to your antidetect browser software.

**📁 2. Search and filter profile groups**

* Select group (Group): The leftmost box (currently showing `All`) helps you quickly filter the list by each separate profile group for easier management.
* Quick search: Type the account name into the `Search profile name...` box to find the exact profile you need to run without having to scroll manually.

**🖱️ 3. How to quickly select multiple profiles at once**

To select the profiles you want to run, you can apply the following super-fast tips:

* Manual selection: Click directly on each profile row.
* Mouse drag: Hold down the left mouse button and drag across the rows to highlight and select a batch of consecutive profiles.
* Using the Shift key: Click to select the first profile, hold down the `Shift` key, then click to select the last profile to select the entire list in between.
* Using the Ctrl key: Hold down the `Ctrl` key and click on scattered profiles to select them individually.
* Select all (Ctrl + A): Click on the list area and press `Ctrl + A` to select all currently displayed profiles.

> 💡 Auto-filter tip: If you checked the feature _Map according to the profile name in column A_ in the Excel setup step (item 2), the system will automatically filter and only keep the profiles whose names exactly match the data in Column A of your Excel file.

After selecting the profiles, the ▶️ Start button in the bottom right corner will light up. Simply click on it to officially start the tool running automatically.
