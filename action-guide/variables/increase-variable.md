# Increase variable

在 Output variable（输出变量）栏位中，您可以填写与原变量相同的名称以累加数值，或填写一个完全不同的变量名称，将结果保存到新变量中，而不改变原变量的值。

* Increase by：想要增加的数量（例如：`1`、`2`、`5`……）。
*   示例：假设您有一个变量 `$row = 5`。

    * 如果 _Output variable_ 填写为 `$row`，_Increase by_ 填写为 `1` ➡️ 变量 `$row` 将增加为 `6`（累加）。
    * 如果 _Output variable_ 填写为 `$nextRow`，_Increase by_ 填写为 `1` ➡️ 变量 `$row` 仍保持为 `5`，而新变量 `$nextRow` 的值将为 `6`。
