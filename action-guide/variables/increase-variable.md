# Increase variable

In the Output variable field, you can enter the same variable name to accumulate the value, or enter a completely different variable name to save the result to a new variable without changing the old variable.

* Increase by: The amount you want to add (Example: `1`, `2`, `5`...).
*   Example: You have a variable `$row = 5`.

    * If you enter `$row` as the _Output variable_ and `1` as the _Increase by_ ➡️ The variable `$row` will increase to `6` (accumulated).
    * If you enter `$nextRow` as the _Output variable_ and `1` as the _Increase by_ ➡️ The variable `$row` remains `5`, while the new variable `$nextRow` will have the value `6`.
