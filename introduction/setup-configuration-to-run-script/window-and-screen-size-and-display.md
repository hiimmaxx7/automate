# 🖥️ 1. Window & screen (Window Size & Display Screen)

* Window Size: Enter the width (X) and height (Y) dimensions for the browser window when the tool runs (for example, in the image it is set to `800 x 600`).
* Scale: The display zoom ratio of the browser (usually left at the default `100%`).
* If you want to run multiple profiles (multiple windows) at the same time, you can adjust the Window Size and Scale parameters to suit your screen resolution and computer configuration. **In simple terms, the smaller the Window Size, the lower the Scale (less than 100%), the higher the screen resolution (2K, 4K), and the more powerful your computer (Xeon CPU, 64GB RAM, etc.), the more threads you can run simultaneously.**
* Screen: Select the screen where you want the browser windows to display when the tool runs (suitable for those using multiple separate monitors).
