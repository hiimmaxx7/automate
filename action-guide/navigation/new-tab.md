# New tab

New tab is a browser control action that automatically opens an additional new blank tab in the running Profile, similar to clicking the plus sign `+` on the browser's tab bar.

🎥 Watch more tutorial video: [Here](https://youtu.be/a9qNt96X1SM).

#### Practical example: Opening an additional new tab to run tasks in parallel

When you are scraping data on a website in the current tab, but need to open another web page (for example: a mail checking page or a crypto wallet retrieval page) to gather coordinating information without wanting to interrupt the old page:

* Configuration method: Drag the New tab action into the flow.
