# Reconnect

Reconnect is the action of reconnecting ADB — resetting the ADB connection between the phone (box phone) and the computer. It is used when the ADB connection is frozen, unstable, or lost, helping the device to receive control commands again without the need to manually unplug/replug the cable. This action does not require configuration parameters.
