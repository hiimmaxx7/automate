# Uninstall app

Uninstall app is the action of completely removing an application from the mobile device by package name.

🎥 Watch the tutorial video: [Here](https://youtu.be/Y3fCTzU9M4U).

#### Explanation of configuration parameters:

* Package name: The package name of the application to uninstall, for example `com.facebook.katana`.
