# Pull file

Pull file 是将文件从手机设备的存储复制到计算机的操作（与 Push file 相反），例如将屏幕截图或结果文件从手机获取到计算机。

#### 配置参数说明：

* Phone file: 设备上的源文件路径，例如 `/storage/emulated/0/Facebook.apk`。
* Local file: 计算机上保存文件的目标路径，例如 `D:\Facebook_573.0.0.37.74_APKPure.apk`。
