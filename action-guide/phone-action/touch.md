# Touch

Touch is the action of tapping on the screen of a mobile device. The touch point can be determined by the XPath of the element or by coordinates.

#### Explanation of configuration parameters:

* Touch type: Choose how to determine the touch point, for example `Touch by Xpath` (tap on the element by XPath).
* XPath: The XPath of the element to tap when using the Touch by Xpath type, for example `//node[@resource-id="com.android.chrome:id/url_bar"]`. See how to get XPath at [Guide to Determine XPath & Coordinates](./xpath-and-coordinates-guide.md).
* Touch mode: Type of touch, for example `Normal` (single normal tap).
