# Screenshot

Screenshot là hành động chụp ảnh màn hình thiết bị điện thoại và lưu file ảnh về máy tính.

🎥 Xem thêm video hướng dẫn: [Tại đây](https://youtu.be/WhRCpYVeagA).

#### Giải thích các tham số cấu hình:

* Output path: Thư mục trên máy tính để lưu ảnh, ví dụ `D:\img`.
* File name: Tên file ảnh, ví dụ `screenshot_1.jpg`.
* Crop area (x,y,w,h): (tuỳ chọn) Vùng cắt của ảnh theo `x,y,w,h` — toạ độ góc trái-trên (x,y) cùng chiều rộng (w) và chiều cao (h). Để trống nếu muốn chụp nguyên màn hình.
