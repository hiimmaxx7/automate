# Push file

Push file 是将任意文件从计算机复制到手机设备存储中的操作（例如，在安装之前将 APK 文件推送到手机，或推送图片/视频以进行发布）。

#### 配置参数说明：

* Local file: 计算机上源文件的路径，例如 `D:\Facebook_573.0.0.37.74_APKPure.apk`。
* Phone file: 设备上保存文件的目标路径，例如 `/storage/emulated/0/Facebook.apk`。
