# Push file

Push file là hành động sao chép một file bất kỳ từ máy tính vào bộ nhớ thiết bị điện thoại (ví dụ đẩy file APK vào máy trước khi cài, hoặc đẩy ảnh/video để đăng bài).

#### Giải thích các tham số cấu hình:

* Local file: Đường dẫn file nguồn trên máy tính, ví dụ `D:\Facebook_573.0.0.37.74_APKPure.apk`.
* Phone file: Đường dẫn đích trên thiết bị nơi lưu file, ví dụ `/storage/emulated/0/Facebook.apk`.
