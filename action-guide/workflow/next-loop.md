# Next loop

Next loop is an action used to immediately stop the actions following it in the current iteration, skipping the remaining code of the loop block (For or While) to jump directly to the next iteration.

Unlike Exit loop (which exits completely and stops the loop entirely), Next loop only skips the current running iteration and continues to execute the subsequent iterations until the list ends. This action is usually placed inside an If block to filter out erroneous or unsuitable data.
