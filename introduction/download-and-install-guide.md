# 📥下载与安装指南

要开始使用 GPM Automate，您可以在 GPM Automate 官网轻松下载，网址如下。

{% embed url="https://gpmautomate.com/" %}

下载完成后，运行 `.exe` 安装文件，然后依次点击“下一步”完成安装步骤即可使用该软件。

📌 重要提示：

请确保您的计算机已安装并打开 GPM Login，因为 Automate 的脚本将直接控制该浏览器上的 Profile。

您只需直接双击 `.gpmlaunch` 文件即可。此时，GPM Automate Runtime 执行程序将自动打开并立即运行脚本，无需您进行任何额外的配置操作。
