# 🔥What is GPM Automate?

#### 🔥 What is GPM Automate? Explained simply

Just imagine GPM Automate as a tool that helps your computer automatically do everything on the GPM Login browser for you. Instead of manually grinding, clicking, typing, and scrolling to do MMO, Crypto Airdrop, account warming, Dropshipping... you just need to command the machine to run automatically across hundreds of profiles at the same time.

This software suite is divided into 2 independent parts, and you choose the one that fits your needs:

**🛠️ GPM Automate Editor – For those who want to WRITE their OWN tool**

* Purpose: This is where you can create, design, and drag-and-drop actions to build an automated script the way you want.
* Output: If you use the free version, you will export a Source Folder to use yourself. If you use the paid version, you will package the script into a single encrypted file called `.gpmlaunch` to sell or share without worrying about the code being exposed.

**🚀 GPM Automate Runtime – For those who ONLY WANT TO RUN a tool (Free)**

* Purpose: This runner has no code-editing function. Its only job is to load the script and run it automatically on GPM Login profiles.
* Target users: If you purchase a script/`.gpmlaunch` file from someone else or buy one on the app marketplace [app.gpmautomate.com](https://app.gpmautomate.com), you only need to use this Runtime part to open the file and run it, without needing to worry about the Editor part.
