# Mouse release

Mouse release 是命令鼠标从按住状态立即释放（松开）左键的操作。此操作没有复杂的配置参数，并且始终是拖放数据操作序列中必须的结束步骤。

🎥 观看更多指导视频：[点击这里](https://youtu.be/kQZWs1I76Zo)。

#### 在命令序列中的实际应用：

此操作与之前的命令结合，以完整地完成模拟任务：

* 步骤 1：使用 `Mouse press and hold` 按住并紧紧抓住验证码滑块或界面中的某个元素。
* 步骤 2：使用 `Mouse move` 拖动鼠标，使该元素移动到目标位置。
* 步骤 3：使用 `Mouse release` 松开鼠标，完成将元素放置在新位置，以便网站系统记录结果。
