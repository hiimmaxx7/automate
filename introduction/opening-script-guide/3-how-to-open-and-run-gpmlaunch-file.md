# 🚀 3. How to open and run the .gpmlaunch file

* Fastest way: simply double click directly on the `.gpmlaunch` file and that's it. The system will automatically launch the GPM Automate Runtime software to open the workflow.
* Centralized management way: you can also open the GPM Automate Runtime software first, then click the `+ Add Application` button and select `Executable file .gpmlaunch` to locate the file you need to run.
