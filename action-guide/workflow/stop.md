# Stop

Stop 是用于立即停止在该位置正在运行的脚本的操作。

> 📌 关于作用范围的注意事项：此操作仅对当前 Profile 正在运行的线程（thread）产生结束作用，不会影响同一批次运行中并行运行的其他线程或其他 Profile。

此操作通常与 If 条件语句块结合使用，用于处理严重错误、无法继续执行脚本的错误，或当该线程已完成主要任务时。

#### 实际示例：账号被 Checkpoint 时停止线程

假设您正在制作养号脚本。当打开浏览器后，如果发现账号已被锁定（Checkpoint），那么继续执行后续操作，如浏览帖子、点赞、发消息等，都是完全没有意义且浪费机器资源的。

* 配置方法：
  * 使用 If 语句块检查错误提示是否出现：`如果出现文字"账号已被锁定"`。
  * 在此 If 语句块内部，调用 Stop 操作。
* 结果：当系统扫描到账号已被锁定时，会执行到 Stop 指令并立即关闭该 Profile 的线程。其他线程中的 Profile 仍会正常继续运行，不受影响。
