# 📥Download and Installation Guide

To start using GPM Automate, you can easily download it from the GPM Automate homepage here.

{% embed url="https://gpmautomate.com/" %}

After downloading, run the `.exe` installation file, then click Next through the installation steps to be able to use the software.

📌 Important note:

Make sure your computer has GPM Login installed and open, as the Automate script will directly control the profiles on this browser.

You just need to double-click directly on the `.gpmlaunch` file. At this point, the GPM Automate Runtime will automatically open and run the script immediately, without requiring you to perform any additional configuration steps.
