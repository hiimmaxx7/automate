# Mouse scroll

Mouse scroll is the action that commands the browser to scroll the page up or down by a fixed, pre-specified number of times (scroll notches). This action helps you actively move the screen to hidden content areas below or above the web page.

🎥 Watch more tutorial video: [Here](https://youtu.be/kQZWs1I76Zo).

#### Configuration parameters:

* Number of scrolls: The number of times (notches) the mouse scroll is performed.
  * _Positive number (Example: `5`)_: Scrolls the screen down 5 times.
  * _Negative number (Example: `-3`)_: Scrolls the screen up 3 times.

#### Practical example: Scroll the screen to load more data or check the interface

When you are browsing a news page or an e-commerce product listing page, you need to scroll down by a fixed short amount to trigger the website's Lazy load feature to load new articles:

* How to configure: Drag the Mouse scroll action into the flow ➔ Enter the value `6` in the _Number of scrolls_ field.
* Result: The browser will scroll down exactly 6 mouse notches decisively to push the screen downward.
