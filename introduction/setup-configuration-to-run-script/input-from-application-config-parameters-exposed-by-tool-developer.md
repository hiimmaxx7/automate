# 📝 3. Input from application (Configuration parameters exposed by the tool creator)

This is an extremely convenient feature when using a `.gpmlaunch` file. When locking the file, the script author intentionally leaves a few blank fields for you to fill in or customize according to your actual needs (similar to the interface you see in the image below).

* Note when running the tool: Each `.gpmlaunch` file from different authors will display different data entry fields in this section (for example: a field for entering wait time, a field for selecting the result file to save, or a field for entering the feature's order number...). Therefore, when you open a script, remember to check whether there are any fields here that need to be filled in, and fill them in according to the tool seller's instructions.
