# Mouse release

Mouse release is the action of commanding the mouse, which is in a pressed state, to immediately release (let go of) the left mouse button. This action does not have complex configuration parameters and is always a mandatory final step for a sequence of drag-and-drop data operations.

🎥 See more instructional video: [Here](https://youtu.be/kQZWs1I76Zo).

#### Practical application in command sequences:

This action combines with previous commands to fully complete a simulated task:

* Step 1: `Mouse press and hold` to press and hold onto the captcha slider or an interface element.
* Step 2: `Mouse move` to drag that element to the target position.
* Step 3: `Mouse release` to let go of the mouse, completing the drop of the element at the new position for the website system to register the result.
