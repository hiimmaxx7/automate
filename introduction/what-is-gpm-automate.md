# 🔥What is GPM Automate?

#### 🔥 What is GPM Automate? In simple terms

Imagine GPM Automate as a tool that helps your computer automatically do everything for you on the GPM Login browser. Instead of having to manually click, type, and scroll to do MMO, Crypto Airdrop, account management, Dropshipping... you just need to command the machine to run in bulk across hundreds of profiles simultaneously.

This software suite is divided into 2 independent parts, depending on your needs to choose the appropriate part:

**🛠️ GPM Automate Editor – For those who want to WRITE their own tools**

* Purpose: It is a place for you to creatively design and drag-and-drop actions to create an automated script according to your preferences.
* Output: If you use the free version, you will export a source folder for personal use. If you use the paid version, you will package the script into a single encrypted file called `.gpmlaunch` to sell for profit or share without worrying about exposing the code.

**🚀 GPM Automate Runtime – For those who ONLY WANT TO RUN tools (Free)**

* Purpose: This runner does not have code editing functions. Its sole task is to load the script and activate it to run automatically on GPM Login profiles.
* Target audience: If you purchase a script/file `.gpmlaunch` from someone else or buy it on the application marketplace [app.gpmautomate.com](https://app.gpmautomate.com), you only need to use this Runtime part to open and run the file, without needing to worry about the Editor part.
