# File read all lines

File read all lines 是用于读取一个 `.txt` 文本文件的操作,并自动将文件中的每一行拆分为一个单独的元素,然后将全部内容保存到输出变量中的一个数组(array)里。

当您有一份按行排列的数据列表(如代理列表、关键词列表、2fa 验证码列表等),并希望使用循环逐行取出处理时,此操作会非常有用。
