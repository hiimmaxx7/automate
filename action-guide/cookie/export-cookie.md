# Export cookie

Export cookie is the action of extracting all current cookie data of the currently open website to store, back up, or transfer for use on other systems or devices.

#### Configuration parameters:

* Cookie file: The path specifying where the data file will be created and written after exporting (Example: `D:\fb_cookie.json`). The exported data will automatically be packaged in standard JSON format.

#### Important operational notes:

* Go to URL is required beforehand: You must also navigate the browser to the website from which you need to get data, wait for the website to fully load, and only then call the Export cookie action to obtain all the current login sessions in full.
