# 📦 1. `.gpmlaunch` 文件是什么？

* 是运行脚本的文件：您可以简单理解为 `.gpmlaunch` 文件就像一个已经从 GPM Automate Editor 工具打包出来的"软件文件"。当有人说"运行脚本"或"运行工具"时，就是指打开这个文件。
* 从哪里获取这个文件：如果您是专业的脚本编写人员，您可以自行构建出这个文件来使用。如果您是普通用户，您可以到应用市场 [`app.gpmautomate.com`](https://app.gpmautomate.com) 购买，或直接向提供服务的一方购买并让他们发送文件给您。
* 绝对安全：该文件已被锁定并对内部源代码进行了加密。购买者只有权限点击运行，而无法查看或修改代码，这样可以帮助脚本编写者在出售到市场时不会泄露"底牌"或被复制心血成果。
