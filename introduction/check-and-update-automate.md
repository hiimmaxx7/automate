# 🔄 How to update scripts on the GPM App Store and distinguish it from updating GPM Automate

Updating the GPM Automate software and updating scripts on the App Store are two separate tasks that do not automatically trigger each other.

🎥 Watch the tutorial video: [Here](https://www.youtube.com/watch?v=THl8V2nO8ew).

* 🖥️ Update GPM Automate: bug fixes, adding new actions for the software itself.
* 📦 Update scripts on the App Store: the author modifies logic/features/fixes bugs for that specific `.gpmlaunch` file.

> To update the script: go to [https://app.gpmautomate.com/profile/apps](https://app.gpmautomate.com/profile/apps) → Purchased Apps section → click Download the app according to the app name that needs updating → reopen the newly downloaded file.
