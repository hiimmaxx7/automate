# Random scroll

Random scroll is an action that instructs the browser to scroll the screen up or down with a completely random distance and speed. This action does not have any accompanying configuration parameters.

🎥 Watch the tutorial video: [Here](https://youtu.be/cCTEtuMtz-s).

#### Practical example: Simulating real user reading behavior (Account warming)

This action is an extremely important "weapon" in account warming scenarios (Facebook, Pinterest, TikTok, Twitter...). If an account is opened and immediately starts clicking continuously or pasting keystrokes at superspeed, the AI systems of social networks will immediately flag it as a Bot and lock the account.

* How to apply: After using the Go to URL action to access the homepage or a detailed post, insert the Random scroll action interspersed with short Delay commands.
* Result: The browser will scroll up, scroll down, pause to view, then continue scrolling randomly again. This helps completely deceive behavior-scanning algorithms, making your Profile look like a real user reading news, maximizing trust for MMO accounts.
